# Rebuilding the data from NASA/JPL sources

Everything in `../data/` can be regenerated from public-domain JPL data with one command. The
build is designed to be deterministic (fixed inputs, pinned packages, coefficient loops in plain
NumPy without BLAS). On the same platform the same inputs give byte-identical tables, manifest and
reference fixture. Across platforms floating-point results differ in the last bits, so a rebuild
elsewhere is numerically equivalent rather than bit-identical (see below).

```sh
sh build/tables/build.sh      # Python venv, pinned packages, downloads DE440s (31 MiB), ~5 minutes
```

`build.sh` creates `build/tables/.venv` (Python 3), installs the pinned packages from
`requirements.txt` (Skyfield 1.55, jplephem 2.24, NumPy 2.5.3, sgp4, certifi), downloads
`de440s.bsp` from JPL into `build/tables/.cache/` and runs `build.py`, which checks the size and
SHA-256 of DE440s before use. The Chiron vectors come from the committed JPL Horizons responses in
`build/tables/sources/horizons/` (orbit solution JPL#171); they are downloaded only if missing.

Output goes to `data/` and `test/fixtures/reference.json`. To build elsewhere and compare:

```sh
ZODIACALLY_EPHEMERIS_OUT_DIR=/tmp/zeph/data ZODIACALLY_EPHEMERIS_FIXTURE=/tmp/zeph/reference.json \
  sh build/tables/build.sh
for f in data/*; do cmp "$f" "/tmp/zeph/$f" && echo "identical $f"; done
cmp test/fixtures/reference.json /tmp/zeph/reference.json && echo "identical fixture"
```

**Verified 8 November 2026 on macOS/arm64 only** (Apple M1, macOS 26, Python 3 from Homebrew):
all 24 files in `data/` (23 table files and `manifest.json`, SHA-256 `dc456976…19c35`) and the
reference fixture came out byte-identical to the committed files built in October 2026.

**Linux x86-64, 9 November 2026** (GitHub Actions, Ubuntu, Python 3.13): the rebuild is not
bit-identical, but the record layout (including every refined sub-record) is identical and the
tables are numerically equivalent. `node build/compare-tables.mjs data <rebuilt data>` bounds the
difference of any evaluated value by the sum of the absolute coefficient differences of a record
(|Tₖ| ≤ 1): at most 0.000000016″ (Uranus sub-records), about 0.000000001–0.000000004″ for most
tables. The directly computed reference values in the fixture differ by at most 0.0000217″
(the Moon at one epoch). The monthly CI job
([`reproducible-build.yml`](../.github/workflows/reproducible-build.yml)) repeats this and fails
if a table differs by more than 0.000001″ or a reference value by more than 0.0001″. If you rebuild
on another platform, please report the result either way.

Other options: `build.py --explore jupiter 16x14 32x16` tests fit error and size for record length ×
coefficients without writing anything; `--only sun,moon` builds single tables for debugging (no
manifest).

**`createdBy` in the manifest.** `data/manifest.json` contains
`"createdBy": "tools/ephemeris-build/build.py 1.1.0"`. That is the builder's path in Zodiacally's
internal repository, where the October 2026 build was made; here the builder is
`build/tables/build.py`. The string is part of the manifest and therefore of its published
SHA-256, so it is kept unchanged, and `build.py` still writes it (`VERSION`) so that a rebuild
stays byte-identical. The `description` in `test/fixtures/reference.json` names the same
internal builder path ("generated by tools/ephemeris-build/build.py") and is kept for the same
reason: `build.py` writes it unchanged, so that a rebuild reproduces the committed fixture byte
for byte.

## Delta T table

`deltaTTable.js` is generated by `build/delta-t/build_delta_t.py` from IERS EOP C04, Bulletin A
(through `astropy-iers-data`), USNO and the published long-term models; the pinned versions and
the full citations are in the script header. See `../docs/maintenance.md` for the yearly refresh.

## Notes

- The detailed German build notes, including the evidence behind each convention and an internal
  Swiss Ephemeris comparison table from the development of 1.1.0 (superseded by the public
  benchmark), are in [`tables/README.de.md`](tables/README.de.md); the English version of the
  conventions is [`../docs/conventions.md`](../docs/conventions.md).
- Clean room: the builder reads only JPL data, through Skyfield, jplephem and NumPy. It never
  imports `sweph` or anything from `../benchmark/`. Three discrete conventions in `reduction.py`
  (light deflection by the Sun only, the polytrope model behind the solar disc, the true-node
  definition) were chosen by comparing residuals against Swiss Ephemeris output and are
  hard-coded; nothing was fitted. The study scripts are in
  [`../benchmark/studies/`](../benchmark/studies/), the details in
  [`../docs/conventions.md`](../docs/conventions.md#how-the-swiss-ephemeris-was-used).
